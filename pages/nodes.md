# Hosting a PlanetLab node

By hosting a PlanetLab node, you contribute to open science. The quickest and easiest way to do so, if you have some capacity on an existing server, is to set up a dedicated VM and run our installation script. Alternatively, if you are in Europe, we can send you a Lenovo mini-PC or a very small Odroid single-board computer, preconfigured as a node that you just need to plug in.

## Host a VM

You do not need to contact us in order to set up a PlanetLab node on a VM. All you need to do is create the VM and run our installation script, and that VM will automatically join the PlanetLab Kubernetes cluster.

Of course, we would be delighted to know who is contributing, and we invite you to create an account on the PlanetLab console and register your node contribution there.

## Receive a mini-PC or single-board computer

Please contact us if you would like us to send you a Lenovo mini-PC or a very small Odroid single-board computer. We send these pre-configured to join the PlanetLab Kubernetes cluster as soon as they are plugged in and connected to the internet. At this time, we are only able to send devices to individuals or institutions in Europe.
