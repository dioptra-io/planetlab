PlanetLab is an open platform serving science and the public interest in the areas of computer networking and distributed systems research. It lets experimenters deploy containerized software on internet-connected hosts located across the globe.

If you know how to use Kubernetes, you already know how to use PlanetLab, as the platform is simply a Kubernetes cluster with extensions that enable it to function at dispersed edge hosts beyond the centralized datacenter.

To get started, [sign up via our web console](https://console.planetlab.io/).
