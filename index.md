PlanetLab is an open platform serving science and the public interest. It lets you develop, deploy, and test containerized software on internet-connected hosts distributed across the globe. A member testbed of the EU's [SLICES-RI](https://www.slices-ri.eu/) research infrastructure, it is built on [EdgeNet](https://github.com/EdgeNet-project/edgenet), a Kubernetes-based system that extends a cluster across dispersed edge hosts, beyond the centralized datacenter. If you know Kubernetes, you already know how to use PlanetLab.

To get started, [sign up via our web console](https://console.planetlab.io/).
